# .github

This repository contains **organization-wide default community health files** for [@LokkerInc](https://github.com/LokkerInc).

> ⚠️ **This repository is public.** Do not commit internal URLs, credentials, secret names, internal tool references, team rosters, or any other non-public information here.

## What's in here

| File | Purpose |
|------|---------|
| `ISSUE_TEMPLATE/` | Default issue templates for all repos |

Files here apply automatically to any repository in the org that doesn't have its own copy.

## What does NOT belong here

- Secret names, even without values
- Internal URLs, hostnames, or IP ranges
- Project keys or internal ticket references
- References to internal tools
- References to internal repos or registries
- Anything copy-pasted from a private repo
- GitHub Actions workflows — these belong in individual repos or a
  dedicated private workflows repo
- On-call rotations, team rosters, or employee contact details
- Anything you wouldn't want exposed on the public internet

## Making changes

All changes must go through a pull request.

If you're unsure whether something is safe to add here, default to **no** and ask.

Thank you!
